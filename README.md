# Celipse

Site institucional da Celipse, desenvolvido com Next.js, TypeScript e Tailwind CSS.
O destaque visual apresenta os aparelhos em grafite, azul noite e prata.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra `http://localhost:3000` no navegador.

## Verificações

```bash
npm run lint
npm run build
```

A página principal fica em `src/app/page.tsx`; estilos globais e a ilustração dos
aparelhos ficam em `src/app/globals.css`.
